# Swing + JGoodies + FlatLaf 샘플 애플리케이션 구현

Java 25 기반의 데스크톱 샘플 애플리케이션을 만들어라.

목적은 **현대적인 Java Swing 애플리케이션을 JGoodies + FlatLaf 조합으로 구축하는 방법을 보여주는 것**이다.

## 1. 절대적인 기술 제약

반드시 다음 기술만 사용한다.

* Java 25
* Swing (`java.desktop`)
* Maven
* JGoodies Forms
* JGoodies Binding
* FlatLaf

다음 기술은 사용하지 않는다.

* JavaFX
* SWT
* Compose Desktop
* Kotlin
* Spring
* Spring Boot
* Electron
* WebView
* React/Vue 등의 웹 UI
* Lombok

**Swing을 버리고 다른 UI 프레임워크로 대체하지 마라.**

---

## 2. 의존성

Maven Central에서 다음 JGoodies 버전을 사용한다.

```xml
<dependency>
    <groupId>com.jgoodies</groupId>
    <artifactId>jgoodies-forms</artifactId>
    <version>1.9.0</version>
</dependency>

<dependency>
    <groupId>com.jgoodies</groupId>
    <artifactId>jgoodies-binding</artifactId>
    <version>2.13.0</version>
</dependency>
```

FlatLaf는 현재 안정적인 Maven Central 버전을 사용한다.

```xml
<dependency>
    <groupId>com.formdev</groupId>
    <artifactId>flatlaf</artifactId>
    <version>...</version>
</dependency>
```

버전을 임의로 오래된 버전으로 고정하지 말고, 현재 사용 가능한 안정 버전을 확인한다.

## 4.1 FlatLaf

애플리케이션 시작 시 FlatLaf를 설정한다.

예:

```java
FlatLightLaf.setup();
```

또는 Dark/Light 전환이 가능하도록 구현한다.

가능하면 Settings 화면에서:

```text
Theme
○ Light
○ Dark
```

를 선택하면 즉시 변경되도록 한다.

# 5. JGoodies Forms

화면 레이아웃에는 가능한 한 JGoodies Forms의 `FormLayout`을 적극적으로 사용한다.

예:

```java
FormLayout layout = new FormLayout(
    "right:pref, 4dlu, fill:pref:grow",
    "pref, 6dlu, pref, 6dlu, pref"
);
```

다음 화면에서는 특히 `FormLayout`을 사용한다.

### Customer 편집 화면

```text
Name        [________________________]

Email       [________________________]

Phone       [________________________]

Status      [ Active ▼               ]

            [ Save ] [ Cancel ]
```

복잡한 `GridBagLayout`을 직접 사용해서 Forms를 우회하지 마라.

---

# 6. JGoodies Binding

JGoodies Binding을 실제 데이터 바인딩에 사용한다.

단순히 dependency만 추가하고 사용하지 않는 것은 금지한다.

예를 들어 다음과 같은 ViewModel/Presentation Model을 만든다.

```java
public class CustomerModel {
    private String name;
    private String email;
    private String phone;
    private boolean active;

    // properties / getters / setters
}
```

그리고 Swing 컴포넌트와 모델을 JGoodies Binding으로 연결한다.

예:

```text
CustomerModel
      │
      │ JGoodies Binding
      ▼
JTextField
JTextField
JTextField
JCheckBox
```

텍스트 필드에서 값을 변경하면 모델에도 반영되고, 모델을 변경하면 UI에도 반영되는 구조를 보여준다.

---

# 7. Presentation Model / MVVM 스타일

JGoodies의 전통적인 용어인 **Presentation Model**을 활용한다.

프로젝트 구조를 대략 다음처럼 구성한다.

```text
src/main/java/
└── com.example.swingapp/
    ├── Application.java
    │
    ├── model/
    │   ├── Customer.java
    │   └── Order.java
    │
    ├── presentation/
    │   ├── CustomerPresentationModel.java
    │   └── DashboardPresentationModel.java
    │
    ├── view/
    │   ├── MainFrame.java
    │   ├── DashboardPanel.java
    │   ├── CustomerPanel.java
    │   └── SettingsPanel.java
    │
    └── service/
        └── CustomerService.java
```

Spring 같은 DI 프레임워크를 사용하지 말고 생성자 주입 등 단순한 Java 방식으로 연결한다.

Navigation에서 메뉴를 클릭하면 중앙 Content가 변경된다.

# 12. JTable

Customer 또는 Order 목록에는 반드시 `JTable`을 사용한다.

가능하면 다음도 구현한다.

* 컬럼 헤더
* 정렬
* 선택
* 행 더블클릭
* 간단한 검색/필터
* 적절한 column width

외부 테이블 UI 라이브러리를 추가하지 않는다.

---

# 13. 구조적인 요구사항

Swing EDT 규칙을 제대로 지킨다.

UI 변경은 EDT에서 수행한다.

```java
SwingUtilities.invokeLater(...)
```

또는 적절한 EDT 패턴을 사용한다.

시간이 오래 걸리는 작업을 EDT에서 실행하지 않는다.

샘플에서는 필요하다면 `SwingWorker`를 이용해 비동기 작업 예제를 보여준다.

# 16. jpackage

이 샘플 프로젝트의 중요한 목적 중 하나가 **Swing 애플리케이션을 독립적인 Windows 프로그램으로 패키징하는 것**이다.

Windows 환경에서 다음과 같이 `.exe` 또는 설치 프로그램을 만들 수 있도록 README에 `jpackage` 사용법을 작성한다.

예:

```bash
jpackage \
  --name SwingModernSample \
  --input target \
  --main-jar swing-modern-sample.jar \
  --type exe
```

실제 프로젝트 구조에 맞게 명령어를 수정한다.

필요하다면 Maven build 결과를 이용한 패키징 방법도 설명한다.

# 17. 모듈 시스템

가능하면 Java 25의 JPMS도 고려한다.

`module-info.java`를 사용하는 경우:

```java
module com.example.swingapp {
    requires java.desktop;

    requires com.jgoodies.forms;
    requires com.jgoodies.binding;
}
```

단, 실제 JGoodies artifact의 module name이 무엇인지 확인한 뒤 정확한 이름을 사용한다.

**존재하지 않는 module name을 추측해서 작성하지 마라.**

JPMS 설정 때문에 프로젝트가 복잡해진다면 classpath 기반 Maven 프로젝트로 단순하게 유지해도 된다.

중요한 것은 실제로 `mvn clean package`가 성공하는 것이다.

# 20. 중요한 원칙

이 프로젝트의 핵심은 "옛날 Swing을 억지로 현대적으로 꾸미는 것"이 아니다.

다음 조합이 실제로 얼마나 실용적인지를 보여주는 샘플이어야 한다.

> **Java 25 + Swing + FlatLaf + JGoodies Forms + JGoodies Binding**

목표는 다음과 같다.

* 빠른 startup
* 낮은 메모리 사용량
* 작은 dependency footprint
* 현대적인 UI
* 유지보수하기 쉬운 구조
* MVVM/Presentation Model에 가까운 구조
* Windows `.exe` 배포 가능

구현 과정에서 JavaFX, Compose, Web UI 등의 대체 기술로 방향을 바꾸지 않는다.
